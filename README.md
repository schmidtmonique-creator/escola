👤 Meu Perfil Acessível

Projeto desenvolvido com HTML5 e CSS3 para apresentar o perfil fictício de um estudante.

📋 Sobre o projeto

A página apresenta informações sobre João, um estudante de 16 anos que cursa Técnico em Desenvolvimento de Sistemas.

O projeto foi criado com foco em:

Clareza das informações;

Organização do conteúdo;

Facilidade de leitura;

Acessibilidade;

Responsividade;

Boa experiência em computadores e celulares.

🗂️ Estrutura do projeto
meu-perfil-acessivel/
│
├── index.html
├── style.css
└── README.md

♿ Recursos de acessibilidade

O projeto utiliza diversas boas práticas de acessibilidade:

HTML semântico;

Títulos organizados com h1, h2 e h3;

Texto alternativo na imagem (alt);

Bom contraste entre texto e fundo;

Fonte simples e fácil de ler;

Espaçamento adequado;

Conteúdo dividido em seções;

Tabela com cabeçalhos;

caption na tabela;

Foco visível no botão;

Layout responsivo;

Textos curtos e objetivos.

📱 Responsividade

A página utiliza CSS com regras @media para adaptar o conteúdo a diferentes tamanhos de tela.

Ela pode ser visualizada em:

💻 Computadores;

📱 Celulares;

📲 Tablets.

🛠️ Tecnologias utilizadas

HTML5

CSS3

🚀 Publicação

O projeto pode ser publicado utilizando o GitHub Pages.

Após enviar os arquivos para o repositório, acesse:

Settings → Pages → Deploy from a branch → main → / (root)

Depois de salvar, o GitHub disponibilizará o endereço da página.
